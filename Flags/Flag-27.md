# Flag 27 – Package Output

## Question
HUNT LEAD: "That's classified material. What did they package it as?"

## Answer
win_update_kb5034.zip


## Finding
The Investigation revealed that the attacker packaged the contents of the targeted avionics directory into an archive named win_update_kb5034.zip. The filename was designed to resemble a legitimate Windows update file, likely as an attempt to disguise sensitive data collection and reduce suspicion during staging and potential exfiltration activities.
